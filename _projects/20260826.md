**Deploy Edge Configurations to AWS EKS**

Because the local edge setup uses standard Kubernetes manifests, moving workloads to AWS EKS requires no changes to the core serving container. Terraform provisions the EKS cluster and GPU worker nodes (g5.xlarge). Custom node launch templates expand the EBS root volumes to accommodate large container images without triggering disk pressure errors.

Model artifacts move from local paths to an S3 bucket accessed via the AWS S3 CSI driver. A Helm chart packages the deployment manifests, allowing ArgoCD to track the repository and apply updates automatically.

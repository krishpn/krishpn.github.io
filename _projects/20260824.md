**Automate Triton Configs with Jinja2**

NVIDIA Triton requires a config.pbtxt file for every model to specify parameters, batch sizes, and tensor formats. Editing these manually across vision, embedding, and language models causes configuration drift and schema errors.

A single catalog YAML file defines input shapes, tensor data types, backends, and streaming flags. A Python script processes this file through a Jinja2 template to produce the required directory structure and configuration files automatically. Changing a batch size or memory limit in the source catalog updates all target configs without manual edits.
